# Changelog

## 0.1.3

- Introduces the first shared Anime3rb design foundation, including reusable design tokens and a shared icon component.
- Adds skeleton loading layouts and consistent error and empty states across the main views.
- Improves image loading placeholders and consistent poster sizing.
- Refines navigation, focus states, player controls, and scrollbar styling.
- Provides Windows installers and Android test APKs through downloadable GitHub Actions artifacts. This is an Actions build, not a published GitHub Release.
