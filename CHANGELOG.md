# Changelog

## 0.1.4

- Refines the video player to align its seek bar, progress gradient, hover preview, settings panel, and control behavior with Anime3rb-Skin.
- Adds more reliable seeking and duration updates, keyboard-focus recovery, and automatic cursor hiding during playback.
- Improves Skip / Next pill reveal and interaction while preserving touch-friendly mobile behavior and app-specific theater, picture-in-picture, lock, and playback-progress features.
- Provides updated Windows installers and Android debug test APKs through GitHub Actions artifacts.

## 0.1.3

- Introduces the first shared Anime3rb design foundation, including reusable design tokens and a shared icon component.
- Adds skeleton loading layouts and consistent error and empty states across the main views.
- Improves image loading placeholders and consistent poster sizing.
- Refines navigation, focus states, player controls, and scrollbar styling.
- Provides Windows installers and Android test APKs through downloadable GitHub Actions artifacts. This is an Actions build, not a published GitHub Release.
